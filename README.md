# Alltid bra mat på Säteriet

En gemensam receptsamling för familjerna och besökande vänner.

## Grundidé

GitHub-repot är källan till sanningen. Varje recept lagras som en Markdown-fil i `recipes/` enligt formatet i `RECIPE_FORMAT.md`.

ChatGPT används som inmatningshjälp: ett recept kan komma som foto, skärmbild, PDF, länk eller vanlig text. ChatGPT läser källan, strukturerar innehållet enligt receptformatet och sparar receptet i repot.

För AI-arbetsflödet, läs `RECIPE_SKILL.md` innan nya recept skapas eller gamla recept ändras.

## Enkel användning

1. Skicka ett foto, PDF, länk eller text med receptet i projektchatten.
2. Skriv exempelvis: **"Lägg in detta recept i samlingen."**
3. ChatGPT ska tolka källan enligt `RECIPE_SKILL.md`.
4. Receptet sparas som Markdown i `recipes/`.
5. Webbplatsen publiceras via GitHub Pages.

## Viktig princip

Källmaterialet får inte "förbättras" i smyg. Om något är otydligt ska det markeras eller frågas om. Egna anpassningar, familjeanteckningar och erfarenheter ska hållas separerade från originalreceptet.
